# Novara Website

Files:
- index.html — homepage
- contact.html — contact/support
- privacy.html — privacy policy
- terms.html — terms of use
- refunds.html — refund policy
- styles.css — shared styling

For a public GitHub Pages site:
1. Create a public repository.
2. Upload all files.
3. Go to Settings -> Pages.
4. Choose Deploy from a branch.
5. Choose main and / (root).
6. GitHub will provide a public `github.io` URL.

Before using the site for live payments, replace the placeholder support email and finalize the legal pages for the actual Novara payment/account setup.
